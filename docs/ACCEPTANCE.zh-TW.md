# 新 Pi 安裝驗收清單

以下清單由全新 Raspberry Pi 3B 上手動驗證。單元測試、既有 Pi 通訊成功，不代表此新硬體已完成驗收。

## 基本安裝（不需更改 U30 部署）

- [ ] 記錄 Pi 型號、`cat /etc/os-release`、`uname -m` 與 repo 的 `git rev-parse HEAD`。
- [ ] `sudo bash install.sh` 正常結束。
- [ ] 連線卡包含這台 Pi 的網址、SSID 及獨立密碼。
- [ ] `python3 /opt/hobo-u30/tools/doctor.py` 顯示三個必要服務 active。
- [ ] 同內網裝置可開啟 Station Overview。
- [ ] 接上 U30 後正確顯示序號、電量及實際通道。
- [ ] 「樹莓派即時採集」開始出現新資料；CSV 時間為 GMT+8。
- [ ] 已有 U30 部署的編號沒有因安裝而改變。
- [ ] `timedatectl status` 顯示時鐘已同步。

## 開機與網路

- [ ] 手動 `sudo reboot` 後，網站與 USB 讀取自動恢復。
- [ ] 拔插 U30 USB 後恢復連線，既有 Pi 資料保留。
- [ ] 接網路線時手機能連設定熱點並開啟 `10.42.0.1:8080`。
- [ ] 網頁設定正確的 2.4 GHz Wi-Fi，拔除網路線後可以從家用網路開啟。
- [ ] 失去已保存 Wi-Fi 時，設定熱點自動恢復。
- [ ] `systemctl list-timers u30-weekly-reboot.timer` 顯示預期的下次執行時間（不必等待一週才能初步檢查）。

## 設定及圖表

- [ ] 由使用者在網頁自行修改密碼；舊密碼不再允許設定，新密碼可用。
- [ ] 熱點使用新密碼可重新連線，家用 Wi-Fi 與 SSH 登入不受影響。
- [ ] 資料查詢與管理排第一，圖表工作區排第二。
- [ ] 新增圖表後可按 × 移除，並可復原最近刪除；感測器資料仍存在。
- [ ] 裁切圖表、篩選與匯出後，檢查來源時間與值相符。

## 選用網頁軟體更新

- [ ] 已設定指定私人倉庫的 Contents 唯讀憑證。輸入錯誤 Pi 設定密碼時無法啟動更新。
- [ ] 安裝版本已是最新版時，檢查更新顯示結果，Pi 維持開機。
- [ ] 可用較新的正式 Release 時，安裝完成後 Pi 自動重開，網頁顯示新版版本，既有資料與設定仍可使用。
- [ ] 模擬下載失敗時，網頁顯示更新失敗，Pi 維持開機。

## 會重新部署 U30 的測試（先保留需要的舊資料）

下列操作會在完整備份成功後清除原生部署，Pi 舊資料保留。備份期間即時讀值暫停數分鐘。

- [ ] 用網頁變更全站頻率，核對原始 BIN／manifest／部署稽核存在且工作成功。
- [ ] U30 與 Pi 採集間隔讀回一致，原生記憶體指標前進。
- [ ] 暫停 U30 後，Pi 仍保存即時資料；按恢復後完成備份並開始新部署。
- [ ] 啟用自動納入：暫停時只接原感測器，再接妥新增感測器；兩次辨識後自動備份／部署，全部實際通道存在。
- [ ] 僅移除感測器不會自動清除部署。
- [ ] 下載或寫入失敗時不會連續重播部署；Pi 仍恢復讀取，網站顯示待處理原因。

## 選用外網

- [ ] 新 Pi 使用獨立 Tunnel／hostname，Cloudflare 顯示 Healthy。
- [ ] 手機行動網路的未登入瀏覽器先出現 Access 驗證頁。
- [ ] 允許的 Email 驗證成功後可開站，未授權 Email 無法存取。
- [ ] 重啟 Pi 後通道恢復。

完整環狀記憶體繞回及其歷史解碼不在本次可保證的驗收項目；原始備份保留，但不將未驗證內容當作成功解碼。
